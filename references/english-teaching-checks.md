# 英语教学情境检查

修改英语模式时使用。检查真实教学决策和证据，不要求固定措辞或所有场景每次都出现。复杂阅读、选词填空和作文检查使用下列可核对的雅思与六级试题。用户追问、错误答案和学习者草稿是为试讲构造的输入，不冒充真实考生记录。语法窄问题仍可用自造短例句。

## 水平与语法

| 情境 | 合格表现 |
|---|---|
| 用户说“我 C1，但不懂过去分词是什么” | 接受其自述并解释所问基础；不据此整体降为初学者，也不因 C1 省略解释。 |
| 用户说“高二，讲这段”，已给完整材料 | 用年级作暂定线索，结合实际知识校准；不强制再交教材、CEFR 等级和考试成绩，不默认全部高中语法已掌握。 |
| 用户用某版教材与课次描述水平 | 作为接触范围使用；具体课内知识需核对，不把课次等同掌握程度。 |
| 用户没有教材且说直接开始；或只问一个词的读音 | 可以开始或直接回答窄问题；不套用日语 N5 水平，不以全面测评阻塞任务。 |
| 新遇到 has been reading | 主动说明名称、have/has + been + 动词-ing 结构、整体时间含义、使用场景及各部分作用；随后回到原句。不能只列公式，也不能断言现在必定仍在进行。 |
| 初次学冠词，询问为什么这里用 the | 先建立 the、a/an、零冠词的分类，再讲语境中的选择；口诀配解释与适用范围，不能把所有建筑名都强加 the。 |
| 用户不懂从句 | 说明当前类别、作用、主从边界、构成和连接成分；补齐未知术语，不只报一个从句名称。 |
| 用户要讲整段，没有选择慢速模式 | 完成指定范围；必要时建议分段，由用户决定，不自行每轮只讲一个词。 |
| 用户能重复原句答案，但在熟悉词汇的新例子中误用规则 | 区分复述与迁移证据，针对错误补讲；允许用户跳过练习继续，不把一次答案当熟练证明。 |

## 理念如何影响练习（待执行的设计检查）

按 [共同教学理念](../SKILL.md#philosophy) 和 [理解检查](../SKILL.md#understanding) 审阅，以下不另设一套规则，也不声称已跑过课堂测试。真实试题仍承担下文的复杂任务检查；这些情境检查练习设计是否只停留在套用。

| 情境 | 应观察到的表现 |
|---|---|
| 学过冠词后，用户要练习实际表达 | 给一个需要介绍事物、继续指代或辨认所指的交流情境，让用户自己组织表达；不在题干标明“第二次提到要用 the”，也不把所有答案预设为 the。依据实际所指和表达判断。 |
| 做完真题中的主体偷换题，用户要再练 | 换主题或信息组织，让用户判断另一段材料支持哪个结论并找证据；不提前说“找主体偷换”。除主体外可能还有条件、范围或证据不足等合理判断，按材料核对。 |
| 学过从句，要求改善一段新草稿 | 让用户先发现哪里需要限定对象、补充信息或重组逻辑，再决定是否合句及怎样合；不把“请用某从句合并指定两句”当作独立发现问题的证明。 |
| 用户能做语法单项题，却在混合任务中认不出同一结构 | 区分形式操练与方法选择的缺口；逐步提示相关关系，再让用户尝试新的情境，不仅追加相同填空。 |
| 用户经老师点明考点后答对 | 记录提示后完成；之后未提示的新任务才用于观察独立识别，不因这次答对认定已掌握迁移。 |

## 两种模式与自动返回

| 情境 | 合格表现 |
|---|---|
| 用户提供一套阅读题并要求讲解 | 进入讲题模式，读取阅读规则并完成指定题目；用户无需手动报模式名。 |
| 用户要求系统讲现在完成进行时 | 进入讲课模式，读取讲课模块，主动讲名称、构成、含义、用法和对照；不强加考试题。 |
| 讲题中出现用户明确没学过的必要结构 | 无需先请求允许切换，实际读取并执行讲课模块；保留题号、原文和判断卡点，补课后返回完成题目。 |
| 补课时发现用户连公式中的基础概念也不会 | 先解释必要基础，回上层结构，再回原题；不反复开场调查，不陷入不停换模块却不完成讲解。 |
| 用户只漏读了一个否定词，相关结构已掌握 | 结合原文纠正具体误读；不因一次错题就自动从头讲一整章。 |
| 用户刚学完规则，下一题再次遇到 | 根据理解证据简短连接；不把刚讲过直接等同于熟练，也不无理由完整重复。 |
| 用户要求只给提示，补课中涉及答案 | 保持提示范围，教必要规则而不借补课公布答案；原任务不变。 |
| 用户要求跳过补课或理解检查，继续讲题 | 遵从明确范围；不能把通过小测或确认懂了作为恢复原题的强制条件。 |
| 同一会话从日语切换为英语讲题 | 使用英语状态和模块，不把日语教材边界、N5 起点或全汉字注音要求套入英语。 |

## 真实试题材料与执行方法

取题入口、页码、题号、来源性质与参考答案依据统一见 [真实试题案例](english-authentic-cases.md)。不得只给试讲者一两句抽出的“题眼”；应提供完整文章、完整相关题目和全部候选项，并隔离答案与本检查文件。

执行时保留实际教学回答、实际读取的模块、逐轮用户输入和材料版本；按行为核对，不能用“规则中写了”代替实际表现。用户追问应等上一轮完成再送入同一会话，以检验进度保留。遇到失败保留原记录，再做定向修复和复查；复查通过不抹去首轮问题。

| 案例 | 真实材料与构造的课堂情境 | 必须从实际回答观察到的行为 |
|---|---|---|
| IELTS-R1 | 剑桥雅思 19 Academic，Test 1，Passage 3 全文；用户自评 C1，28 选 D、30 选 B、39 选 YES，先讲 28，只定位 30，39 留待后续 | 在完整长文中准确定位，解释时间、范围与主体偷换；遵守各题不同披露进度，不自行把整篇变成逐词慢讲。 |
| IELTS-R2 | 同一会话中用户插问监管段的介词前置与关系从句，明确该基础没学懂，暂不公布 30 | 实际读取讲课模块，教类别、结构、作用及必要术语，随后应用到原文；不因 C1 省略基础，也不整体降级。 |
| IELTS-R3 | 下一轮只说“接着刚才没讲完的题，另外留下的判断题也一起讲” | 准确回到 30、39，不重讲 28；分别给多句证据、诱导来源与判断，不把理解小测设成返回门槛。 |
| IELTS-R4 | 用户由第 30 题推断“监管和纠错根本没用”，要求联系全文不同段落 | 联结概述、监管局限、纠错条件和结尾；区分能力受限与毫无作用，区分未来希望与已有成效。该追问是课堂构造，不是官方新增题。 |
| CET-R | 2024 年 6 月六级，讽刺与机智文章及 46–50 完整题组，用户 49 选 A、50 选 B | 49 综合两类受益者的证据，找出 A 主体偷换；50 对照不同段落的动机与受欢迎程度，不靠选项关键词重合。 |
| CET-G | 同卷彩虹选词填空 26–35 全文及 15 词词库，重点 32–35 | 同时检查句法位置、词义、搭配、上下文与词库约束；指出所选干扰词何处不合，而非背答案或只凭物理常识。 |
| IELTS-W | 同册 Test 1 Task 2，竞争与合作题；配一篇至少 250 词、语言较通顺却只谈技术便利的构造草稿 | 首先识别没有讨论题目双方观点；允许整段删除、重写论证。局部示范解释词句与论证选择，不未经请求给完整范文。 |

## 作文：从用户原稿诊断和重建

| 情境 | 合格表现 |
|---|---|
| 用户只有作文题，要求辅导，没有请求范文 | 鼓励自己写并拍照上传，接受粘贴文字；可帮助理解题目或形成要点，不直接生成整篇范文。 |
| 用户已粘贴一段草稿，或说无法写完整篇 | 从现有内容或构思开始；不强迫重新手写拍照，不等整篇齐全才提供帮助。 |
| 照片上某个词字迹模糊 | 标记并确认；原稿和修改分开，不把猜读当作用户的真实语法错误。 |
| 用户说“改成范文水平” | 讲解怎样改善自己的文章；这句话本身不触发整篇代写。 |
| 用户说“给一篇完整范文” | 尊重明确请求，可交付指定范文；不机械坚持必须先写草稿。 |
| 草稿有普通但准确的词，用户想用高级词 | 解释原词为何合适；替换建议考虑语义、搭配和语体，允许保留。 |
| 两个独立句只有逗号相连 | 解释连接问题并提供符合含义的连接或拆句方法，不把任意逗号拼接叫复合句。 |
| 同一段每句都加 moreover 或 however | 检查真实逻辑关系，必要时删掉连接词或重组句子，不一味再添加“高级衔接”。 |
| 文章重复、跑题、论证混乱，很多句子没有价值 | 先诊断全篇并决定删、移、合、补、重写；对冗余句可成组说明后删除，不逐句硬找优点或保留每句原意。解释改动目的，保留真实信息与核心意图。 |
| 重建论证需要用户没有提供的个人经历或事实 | 指出缺口，引导用户补充或把新增内容明确作为建议；不伪造经历使文章看似更好。 |
| 用户明确要求整合已讨论的删改 | 可以交付完整修订版，允许句子数量和顺序变化；重要取舍可追溯，不要求逐句对应原文。 |

复杂作文主案例使用上表 IELTS-W。真实题目与构造草稿必须分别标明来源；也可换用用户已授权的真实草稿，但不能把考试范文伪装成用户作文。教材级别、无教材、只问读音、模糊图片和日英切换等表中情境仍需独立检查，不能因真题试讲通过就默认全覆盖。

## 校验边界

以上场景用于实际审阅或独立教学测试。报告分别列明：已执行的课堂场景及证据、未执行的场景、失败与复查、仅完成静态审查的规则。少量代理试讲不等于真实学生已学会，也不等于所有复杂任务可靠；不得以答对题目代替对解释质量、返回进度和证据准确性的检查。
